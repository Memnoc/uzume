# Nature-inspired acronym names

Date: 2026-11-08. Status: exploratory shortlist; no name selected or legally cleared.

## Brief

Find friendly, pronounceable names with natural imagery, following the user's
positive response to Maple. The expansion should describe the personal, modular,
native Neovim editor and its agent/review workflow. Prefer practical differentiation
from existing editors, Neovim distributions, and coding-agent tools; an unrelated
use is a caveat, not an automatic legal prohibition.

## Candidates worth discussing

The expansions below are newly proposed branding, not established meanings of
the words. Assessments are our interpretation of a limited web screen.

| Name | Proposed expansion | Symbol and meaning | Initial software screen |
| --- | --- | --- | --- |
| **Larice** | **L**ocal **A**gent **R**eview **I**nterface for **C**ode **E**diting | Italian for larch: a tree silhouette or needle-covered branch. [Cambridge dictionary](https://dictionary.cambridge.org/us/dictionary/italian-english/larice) | Exact-name searches with editor, Neovim, AI agent, and GitHub did not identify a directly competing product. The name is already used by a [Salesforce consultancy](https://larice.africa/services/). Promising for a closer screen, not an unclaimed name. |
| **Borage** | **B**ranch-**O**riented **R**eview and **A**gent-**G**uided **E**diting | A flowering plant with star-like blue flowers, offering both flower and star motifs. [Royal Horticultural Society](https://www.rhs.org.uk/plants/borage?type=0) | Targeted editor/software/GitHub searches did not identify a directly competing editor or coding-agent product. A [secondary company directory](https://cincodias.elpais.com/directorio-empresas/empresa/5871159/borage) lists BORAGE SL with software-related activity; this was not verified against a first-party company source and remains a follow-up lead. |
| **Samara** | **S**tructured **A**gent **M**anagement **A**nd **R**eview **A**pplication | A winged fruit; maples produce paired samaras. Retains the maple association with a seed/wing motif. [Arnold Arboretum](https://arboretum.harvard.edu/arnoldia-stories/model-maples/) | Exact-name searches with code editor, text editor, Neovim, and terminal agent did not identify a directly competing product. However, [Samara](https://www.samarawell.com/) already markets a healthcare AI platform and AI teams, and [Samara Stack](https://samarastack.com/en/) is a developer-learning directory. More crowded in AI than Larice. |

Larice is the strongest match for the Italian connection and the editor/review
brief. Borage has a good modular/branching association and a compact visual motif.
Samara preserves the strongest connection to Maple, but its healthcare AI use
needs explicit consideration. None is recommended as legally available.

## Names screened out of this round

These existing uses are closer to the intended product, or make differentiation
less attractive. This is not a finding of infringement.

- **Larch:** an existing [hierarchical-document editor](https://jeffreyellis.org/software/).
- **Linden:** an existing [LLM workflow and agent engine](https://github.com/matstech/linden).
- **Sorrel:** an existing [Git-compatible agent-work review platform](https://sorrelhub.com/), as well as a [JetBrains licence-checking plugin](https://github.com/JetBrains-Research/sorrel).
- **Mallow:** an existing [Markdown editor](https://github.com/gurumdeva/mallow).
- **Brome:** an existing [multi-model AI workspace](https://brome.ai/).
- **Pipit:** a [web code editor](https://git.w33ble.com/w33ble/pipit) and [coding-agent project](https://github.com/sushanthpy/pipit).
- **Felce:** an existing [low-code software project](https://github.com/fe-lce).
- **Bramble:** existing [editor](https://github.com/GrimoireGL/bramble) and [agent-terminal project](https://github.com/bazelment/yoloswe) uses.

## Limits

This is a preliminary product-name screen, primarily grounded in official product
sites and source repositories. The Borage company-directory lead is explicitly
secondary and unverified. Search absence is not evidence that a name is available.
No trademark-register clearance, current territorial registration verification,
domain availability, or package/command namespace reservation was performed.
Before a final rename, investigate the selected name and close variants in the
intended territories. The earlier [name screen](2026-11-08-name-screening.md)
records the distinction between naming collisions, trademarks, and copyright.
