# Warm, short acronym candidates

Date: 2026-11-08. Status: exploratory; no name selected or legally cleared.

The user likes the sound and memorability of Lira, Maple and Melo, but wants
alternatives after existing editor and AI-workspace uses surfaced. This round
prioritizes familiar, pronounceable names with expansions grounded in the actual
editor workflow. Expansions are proposed branding, not the existing projects'
meanings.

| Name | Proposed expansion | Verified existing-use caveats |
| --- | --- | --- |
| **Pina** | **P**ersonal **I**nterface for **N**eovim and **A**gents | [PINA](https://github.com/PINA-org/PINA) is a scientific machine-learning library that also supplies agent guides. [Pina](https://github.com/bjarneo/omarchy-pina-theme) is an Omarchy desktop theme. Neither is a standalone code editor, but the theme overlaps the terminal/editor audience. |
| **Perla** | **P**ersonal **E**ditor for **R**eview and **L**ocal **A**gents | [Perla](https://angelmunoz.github.io/Perla/) already names a front-end development server. That is a developer-tool collision even though it is not an editor. |
| **Pesco** | **P**ersonal **E**ditor for **S**hells, **C**ode and **O**rchestration | PeSCo already names a software-verification approach/tool, documented in an [authors' research paper](https://link.springer.com/chapter/10.1007/978-3-030-17502-3_19). Its [implementation repository](https://github.com/cedricrupb/pySVRanker) refers to PeSCo. This is another developer/research-tool use. |
| **Pelmo** | **P**ersonal **E**ditor for **L**ocal **M**odular **O**rchestration | [PELMO](https://esdac.jrc.ec.europa.eu/projects/pelmo) already names pesticide-simulation software. Its subject matter is substantially different from an editor, but the software name is not unclaimed. |

Targeted searches did not surface a directly competing same-name code editor or
coding-agent workspace for these four candidates. That observation is limited
to this search and is not evidence of availability. Existing uses vary in
relevance; unrelated software is not automatically a legal prohibition.

No trademark-register clearance, territorial rights verification, domain check,
or package/command namespace reservation was performed. A selected finalist and
close variants need a focused assessment before renaming the distribution.

Pimo and Elmo were screened out because existing [Pimo notes editing](https://github.com/higgn/pimo-popup-notes)
and [Elmo modal editing](https://pkg.go.dev/github.com/Ardelean-Calin/elmo)
provide closer editor-name overlaps.
