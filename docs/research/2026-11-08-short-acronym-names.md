# Short acronym names

Date: 2026-11-08. Preliminary name screen; no selection or legal clearance.

The user rejected Larice, Borage and Samara. This round returns to short,
pronounceable expansions of personal editor, modularity and agents. Expansions
are proposed branding, not the existing products' meanings.

| Candidate | Proposed expansion | Existing uses and assessment |
| --- | --- | --- |
| **Mela** | **M**odular **E**ditor for **L**ocal **A**gents | [Mela](https://www.usemela.com/features/content-modeling) already names a CMS with visual content editing. Its [MCP integration](https://www.usemela.com/features/mcp-server) supports Claude Code and Cursor for website scaffolding. Separately, [Mela Recipes](https://mela.recipes/) is a recipe manager for macOS/iOS. These are not standalone code editors, but there is developer-tool and agent-adjacent overlap. Strong expansion, with meaningful existing-use caveats. |
| **Pema** | **P**ersonal **E**ditor with **M**odular **A**gents | Existing scientific software includes an [R package](https://github.com/cjvanlissa/pema) and an [environmental DNA analysis pipeline](https://github.com/hariszaf/pema). This screen did not identify a directly competing editor or coding-agent workspace. Potential discussion candidate, with existing software names disclosed. |
| **Nelma** | **N**eovim **E**ditor for **L**ocal **M**odular **A**gents | Targeted editor/Neovim/agent searches did not surface a direct competitor. Existing app use includes [Nelma for Counselors](https://apps.apple.com/ru/app/nelma-for-counselors/id1592268497). This is an unrelated-use caveat, not availability or legal clearance. |
| **Ampe** | **A**gent-powered **M**odular **P**ersonal **E**ditor | Existing uses include [AI car-rental pricing software](https://www.ampe.ai/) and [LLNL simulation software](https://github.com/LLNL/AMPE). A [1988 Columbia thesis](https://mice.cs.columbia.edu/getTechreport.php?format=pdf&techreportID=1141) also describes AMPE, a programming environment incorporating a structure editor. No current same-name Neovim or coding-agent workspace surfaced, but this is not a name without editor history. |

Pema has the least direct editor/workspace overlap among these findings; that is
a practical judgment, not a trademark conclusion. Mela has the cleanest expansion
but the CMS deserves closer investigation before adoption. Ampe is the most
qualified option because of its established software uses and historical editor.

This screen used official product pages, source repositories and a university
thesis. Searches cannot establish absence. No current trademark-register checks,
territorial rights verification, domain availability or package-name reservation
were performed. Existing unrelated software does not automatically prohibit a
name. The selected finalist and close variants still need a focused assessment.
