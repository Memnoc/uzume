# Greek and Japanese mythology names

Date: 2026-11-08. Decision: Memnoc selected **Uzume** after this screen. The name has not been legally cleared. The findings below record the comparison that informed the choice.

This round follows the user's preference for evocative names and narrows the
search to Greek and Japanese mythology. Acronyms are not required. The project
associations below are our branding interpretations, distinct from the cited
mythology.

| Name | Verified mythology | Proposed project association | Existing software uses |
| --- | --- | --- | --- |
| **Uzume** | Short form of Ame-no-Uzume, whose dance helped draw Amaterasu from the heavenly cave. [Kokugakuin University](https://d-museum.kokugakuin.ac.jp/eos/detail/?id=9422) associates her character with laughter and harmony. | Creative problem-solving; a short, memorable name for a personal working environment. | [Uzume](https://uzume.tanukisoftworks.com/) is a Rust Discord music-presence utility; [uzume_vocoder](https://github.com/haruneko/uzume_vocoder) is an audio-synthesis wrapper library. These are software overlaps, but neither is a code editor. |
| **Kuebiko** | A scarecrow-associated kami unable to walk but possessing broad knowledge of the world. [Kokugakuin University](https://d-museum.kokugakuin.ac.jp/eos/detail/?id=9372). | Quiet observation and understanding: particularly suitable for reading and reviewing code. | [Kuebiko](https://github.com/adi-panda/Kuebiko) is an AI Twitch chatbot; another [Kuebiko](https://github.com/kamonegi13/kuebiko) uses a local LLM to produce threat-intelligence briefings. These are adjacent AI uses. |
| **Hestia** | Greek goddess of the hearth. [Dumbarton Oaks museum](https://museum.doaks.org/objects-1/info/27440). | A stable home for projects, windows and agents. | [Hestia](https://github.com/dylan-okeefe/hestia) already names a local agent framework, a close functional overlap. |
| **Ariadne** | Her thread helped Theseus navigate the Labyrinth. [Acropolis Museum](https://www.theacropolismuseum.gr/en/node/1015). | Finding a path through code and parallel work without losing context. | Existing [Claude Code memory tooling](https://rikalim.com/ai-lab/ariadne/) and an [editor assistant](https://docs.getpoiesis.com/ariadne/) make this a crowded, closely related name. |

**Uzume is the strongest preliminary fit** for brevity and relative separation
from the editor/agent category. Kuebiko has a strong review-oriented story but
more adjacent AI usage. Hestia and Ariadne have clear stories, with substantially
closer software overlaps.

Omoikane was excluded despite its apt wisdom/deliberation association: it already
names a [knowledge-base server for coding agents](https://github.com/zenryokukikai/omoikane).

The limited targeted web screen did not surface a same-name code editor for
Uzume or Kuebiko. This is not evidence of availability. Existing unrelated uses
are not automatically legal prohibitions; trademark rights, jurisdictions,
domains and package/command namespaces were not cleared.
